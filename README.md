# Tidy3D Photonics Examples

This repository collects worked examples from our photonics research using
[Tidy3D](https://github.com/flexcompute/tidy3d). We develop and maintain
the notebooks here as we prepare selected tutorials for submission to the
Tidy3D Library of Examples.

## Examples

| Tutorial | Guiding question | Status |
| --- | --- | --- |
| [Simulating a multilayer spaceplate](examples/multilayer-spaceplate/) | How can we use the transmitted optical field to measure the effective propagation distance of a multilayer stack? | In development |

## Running a tutorial

Each tutorial has its own folder under `examples/`. Start with the Jupyter
notebook in that folder. Its opening section lists the required packages
and data files and identifies any steps that submit simulations to the
Tidy3D cloud.

## Authors and citation

Each tutorial credits its contributors and links to the paper it accompanies,
